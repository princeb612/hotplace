# C++14 compatibility entry point

## 1. Role

`c++14.hpp` is a narrow include wrapper for `string/constexpr_obfuscate.hpp`. It does not enable C++14 across the SDK or provide a general C++14 compatibility layer.

## 2. Data Model

The included header declares compile-time string-obfuscation templates and macros only when `__cplusplus >= 201402L`. Under the project's general C++11 baseline, those declarations are not enabled.

## 3. Behavior Model

Including this file brings in the constexpr-obfuscation implementation. The feature stores transformed character data in a constexpr object and reconstructs a `std::string` when `load_string()` is called. It is an obfuscation convenience, not cryptographic encryption; a determined reader can recover the original string from the transformation logic.

The `valist` testcase contains a compile-time branch guarded by `__cplusplus >= 201402L`. In C++14-or-later builds it exercises newer convenience calls; under the general C++11 baseline, the branch reports `not_supported`. This remains an isolated newer-standard experiment, not a project-wide language requirement.
