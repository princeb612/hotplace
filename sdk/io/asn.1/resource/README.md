# ASN.1 Parser Resources

`asn.1/resource` contains generated/configuration-oriented source resources used by the ASN.1 parser setup.

The current files provide parser configuration/resource definitions for the LALR/GLR parser variants. They are support resources rather than the primary ASN.1 semantic implementation.

## Related areas

- `../basic/` — ASN.1 semantic model
- `../../parser/` — parser infrastructure
- `../loader/` — loading flow

These files should be treated as parser resource/configuration material when reviewing the ASN.1 implementation.
